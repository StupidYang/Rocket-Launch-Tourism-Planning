    从看板到出行，还差三次确认

    任务确认：去官方核对日期、北京时间与具体发射场，不拿NET或TBD锁定不可退机票。

    入场确认：观礼票、车辆预约、场区参观是三个不同申请；核对当次开放与延期退款。

    行程确认：从北京出发，按海南、酒泉及其他场址分别规划交通和延期缓冲。周四晚至周一仅适用于合适的海南窗口。

    数据来源、覆盖边界与运行方式

    任务源为The Space Devs维护的Launch Library 2，属于第三方公开数据，非中国官方发射排期。运营方属性只按已识别的中国运营主体归类，未知主体保留“未分类”；在商业发射场发射不等于民营火箭。

    GitHub Actions每6小时拉取一次全量分页。分页失败、返回空表或重复ID时保留上一份完整快照，并更新错误状态。超过18小时未成功更新会提示过期。页面刷新只重新读取站点快照，不会反复请求源API。
