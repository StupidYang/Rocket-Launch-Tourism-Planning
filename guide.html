预约申请：三件事，分别办

没有一张通用的“全国火箭观礼许可证”。门票、车辆预约、场区或科普参观不是一回事。

A · 观礼票 / 开放区域

确认任务、观礼地址、可见工位、最晚入场、集合、散场与延期退款。合法公共区域是否开放、是否收费也按当次安排，不默认任何海滩都能进。

门票 ≠ 内场通行，付款 ≠ 保证发射。

B · 车辆预约

按公安通知填写车牌、人数、时段、区域，保存成功记录。司机、租车或包车方负责落实；租车换牌要重新核对，步行也受区域管制。[11]

车辆预约成功 ≠ 买好观礼票。

C · 场区 / 科普参观

单独询问开放时段、有效证件、身份要求与发射前后停开安排。历史活动限制不能直接当2027通用规则。

白天参观票 ≠ 发射日内场观礼。

完整办理顺序

1. 核对任务：记录名称、北京时间、发射场与工位、来源及发布时间。某月择机只能进入候选池。

2. 先问再付款：通过核验过的公众号菜单或公示客服确认营业、余位、视线、集合与散场，不把私人收款码当官方渠道。

3. 锁定退改：机票看退改费、差价与截止时间；四晚酒店、门票与接驳要有书面延期规则。“可改签”不是免费改签。

4. 办交通预约：历史路径为“诚信文昌” → 航天发射车辆预约 → 登录 → 小车/大巴 → 东郊/龙楼区域 → 车牌、人数、时段、方向。2027以当次通知为准。[11]

5. 最晚退改前做去 / 不去决定：同时核验任务、观礼、道路与返程，任一关键条件不成立就换周。

历史价格不是2027全年报价。国航合作页曾列瑶光门市价388元、合资格优惠330元，活动截止2027-03-31；清明与五一不自动享受旧优惠。场次、票种、条件与退改仍须询问。[09][10]

延期、安全与止损规则

窗口变化

技术、天气、空域与任务状态都可能影响排期。官宣也不是百分百按时发射；观礼退款不自动覆盖机票和酒店。

合法观礼

不闯封控、不翻围栏、不擅入封闭海滩，不携无人机追拍。装备、充电宝和行李规定出行前查航司与民航最新要求。

身体与返程

防晒防雨、备水与简餐、舒适鞋和耳塞，别疲劳驾驶。周日晚场与周一返京有冲突时，提前明确返程优先的边界。

止损节点：出发前任务与入场条件未成立，优先改周；周五顺延周六继续等；周日深夜重新评估休息与交通；推到周一以后不再等。不要被已经花出去的钱绑住后续决定。
